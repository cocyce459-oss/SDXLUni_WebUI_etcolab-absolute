### 🛰️ Fast Setup Workflow (Colab / Linux)

The following sequence provides a streamlined installation path using Astral `uv` and a minimal dependency footprint:

```bash
# 1. Install the hyper-fast Astral UV package manager
pip install -q --upgrade uv

# 2. Clone the Neo branch
git clone --branch neo --depth 1 https://github.com/Haoming02/sd-webui-forge-classic sd-webui-forge-neo
cd sd-webui-forge-neo

# 3. Create an isolated Python 3.13 environment
uv venv venv --python 3.13 --seed

# 4. Set runtime environment flags
export TORCH_INDEX_URL="https://download.pytorch.org/whl/cu130"
export TORCH_COMMAND="pip install torch==2.13.0+cu130 torchvision==0.28.0+cu130 --extra-index-url ${TORCH_INDEX_URL}"
export GRADIO_PACKAGE="gradio==4.40.0 gradio_rangeslider==0.0.8"
export XFORMERS_PACKAGE="xformers==0.0.35 --extra-index-url ${TORCH_INDEX_URL}"
export TORCH_FORCE_NO_WEIGHTS_ONLY_LOAD="true"

# 5. Launch with cloud-oriented defaults
export COMMANDLINE_ARGS="--no-download-sd-model --xformers --listen --port 7860 --expandable-segments --api"
./venv/bin/python launch.py
```

### ⚙️ Engine Innovations and Workflow Features

* 🎛️ **Deterministic Preset System**: Fully rewritten preset logic stores checkpoint states, module selections, and sampler parameters independently per preset.
* 📐 **Resolution Step Enforcement**: Hard-locked multiples of 64 ensure tensor geometry remains aligned and predictable.
* 🏎️ **Astral `uv` Acceleration**: Replaces slow package resolution paths with a faster and more deterministic environment setup.
* 🌟 **Spectrum Acceleration**: Training-free performance enhancements across supported model families.
* ⚡ **Torch Compile**: Runtime optimization with minimal overhead after the initial warm-up cycle.
* 🎨 **RescaleCFG and MaHiRo**:
  * **RescaleCFG**: Reduces oversaturation and color burn artifacts in high-CFG generation.
  * **MaHiRo**: Alternative weighting strategy that improves prompt adherence.
* 🧱 **Tiled Conv2d VAE Engine**: Reduces memory pressure during latent decoding for SD1 and SDXL workflows.
* 🎭 **Next-Generation ControlNet Ecosystem**:
  * **LLLite**: Lightweight control for SDXL and Anima with `MultiDiffusion` integration.
  * **Union ControlNet**: Support for SDXL 1.0 Union and Chenkin UniControl-XL.
  * **Region ControlNet**: Color-masked regional generation for Anima.
  * **Dynamic LoRA Control**: Syntax such as `<lora:name:[w1@t1, w2@t2, ...]>` for time-step-specific injection.

## 💻 Commandline Flags and Neo Optimizations

Commandline flags can be added to `COMMANDLINE_ARGS` in `webui-user.bat` (Windows) or `webui-user.sh` (Linux/macOS):

```bash
# Example: High-performance configuration
set COMMANDLINE_ARGS=--uv --cuda-malloc --expandable-segments --fast-fp8 --xformers
```

### ⚡ Core and Memory Acceleration
* `--cuda-malloc` — Enables CUDA native memory allocation to reduce heap fragmentation.
* `--cuda-stream` — Supports non-blocking tensor streaming between CPU and GPU memory.
* `--pin-shared-memory` — Pins shared memory to maximize transfer throughput.
* `--expandable-segments` — Uses PyTorch expandable segment allocation to smooth bursty memory demands.
* `--pynvml` — Queries NVIDIA management APIs for accurate VRAM monitoring.

### 📦 Astral UV System
* `--uv` — Replaces slower package resolution with Astral `uv`.
* `--uv-symlink` — Uses symlink-based linking to reduce environment footprint.
* `--uv-local-cache` — Stores package cache in `.uv-cache` under the project root for portable setups.

### 📁 Unified Storage and Cross-Tool References
* `--model-ref <DIR>` — Directs the application to a centralized external model vault.
* `--forge-ref-a1111-home <DIR>` — Shares checkpoints and assets from an existing AUTOMATIC1111 installation.
* `--forge-ref-comfy-home <DIR>` — Maps directly to a ComfyUI installation directory.
* `--forge-ref-comfy-yaml <PATH>` — Reads `extra_model_paths.yaml` entries from ComfyUI.

### 🔮 Compute, Attention, and Precision
* `--xformers` — Installs and links memory-efficient cross-attention kernels.
* `--sage` — Enables `sageattention` with Triton bindings.
* `--flash` — Installs and compiles `flash_attn` for high-throughput attention.
* `--use-ck-attention` — Enables **Comfy-Kitchen Attention**.
* `--enable-triton-backend` — Activates Triton-backed compute acceleration.
* `--fast-fp8` — Uses native hardware `torch._scaled_mm` optimizations for `float8_e4m3fn` workloads.
* `--fast-fp16` — Enables `allow_fp16_accumulation` for supported kernels.
* `--tiled-conv2d <SIZE>` — Tiles VAE convolution into manageable chunks (`64`, `128`, `256`, `512`).
* `--autotune` — Enables `torch.backends.cudnn.benchmark` profiling.

### 1. Prerequisites
* **Git**: [Download Git](https://git-scm.com/downloads)

<details open>

Forge Neo evaluates the runtime environment and selects the fastest viable attention backend according to system compatibility:

```text
┌──────────────────────────────────────────────────────────────┐
│  1. SageAttention   (Fastest, requires Triton)               │

```

## 📋 Troubleshooting Guide

| Symptom / Error | Root Cause | Recommended Resolution |
|:---|:---|:---|
| `uv: command not found` | `--uv` is enabled without the `uv` binary on the system | Run `pip install --upgrade uv` or install via the official Astral installer |
| `This program is tested with 3.13.12` | The environment is running an older Python version | Use `uv venv venv --python 3.13 --seed` to create a clean CPython 3.13 environment |
| `Please update your GPU driver to support cu130` | NVIDIA driver is older than the compatible threshold | Update drivers or switch to the `cu128` package set via `TORCH_INDEX_URL` |
| `AssertionError: Torch not compiled with CUDA` | A CPU-only wheel was installed incorrectly | Remove the current virtual environment and reinstall using the pinned `TORCH_COMMAND` |
| `UI blank / slider components broken` | Gradio version mismatch or dependency conflict | Reinstall with `gradio==4.40.0` and `gradio_rangeslider==0.0.8` |
| `ADetailer unpickle / module crash` | Legacy ADetailer fork is incompatible with Gradio 4 | Use `abzaloff/aadetailer-neoforge` and set `TORCH_FORCE_NO_WEIGHTS_ONLY_LOAD=true` |
| `CUDA Out Of Memory (OOM)` | Large resolution workloads exceed available VRAM | Add `--expandable-segments --tiled-conv2d 256` and enable Low Bits in Settings |

## 📜 Issues and Community Guidelines

To maintain a stable and productive project environment, contributors are asked to follow a concise set of expectations:

* **Removed Features**: Requests to reintroduce intentionally retired legacy modules (SD2, Hypernetworks, obsolete hooks) will not be accepted.
* **Non-Official Quantizations**: Issues caused by unofficial model conversions or corrupted weights are outside the supported scope.
* **Third-Party Extensions**: Extensions must adapt to the current UI architecture rather than reintroducing legacy behavior.
* **Reproducibility**: Bug reports should be reproducible on a clean git installation and include the relevant launch arguments and environment details.
* **Safety and Respect**: Public bug threads must remain respectful and free from offensive or NSFW content.
